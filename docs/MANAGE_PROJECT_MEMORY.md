# PURPOSE & CONTEXT

VAXINXBOT is an Applied Engineering AI Operating System built by Skreggie.

Originally created as CS50-CHATBOT-001, the project has evolved beyond a simple CS50 study companion into a reusable engineering framework for knowledge management, documentation, AI collaboration, workflow automation, and project storytelling.

The system remains local-first and browser-based, built with:

* HTML
* CSS
* JavaScript

Persistence is handled through localStorage.

No backend is currently required.

---
