# VLA_Index.md

Purpose:

Master registry of all Visual Lore Artifacts (VLAs).

Tracks:

* VLA Number
* Title
* Project
* Implementation Phase
* Learning Source
* Status

Example:

```text
VLA_001 | TPS Building Foundation
Project: VAXINX-QC-VISION
Phase: IMPLEMENTATION_001
Source: Toyota TPS
Status: LOCKED

VLA_008 | Visual SLAM Discovery
Project: VAXINX-QC-VISION
Phase: IMPLEMENTATION_001
Source: NVIDIA AI Academy
Status: DISCOVERED
```
